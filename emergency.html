🚨 緊急時の対処法

🌡️ 熱中症（最も危険！）

症状

  • ハアハアが激しく止まらない
  • よだれが大量に出る
  • ぐったりして立てない
  • 歯茎・舌が赤紫色になる
  • 嘔吐・下痢
  • 意識が朦朧としている

応急処置

  1. すぐに日陰・冷房の効いた場所へ
  2. 水（常温）を体にかけて冷やす
  3. 首・脇・股を重点的に冷やす
  4. 扇風機・うちわで風を当てる
  5. 意識があれば水を少量ずつ飲ませる
  6. すぐに動物病院へ！

やってはいけないこと

  • 氷水・冷水で急激に冷やす（体温が急降下）
  • 水を無理やり飲ませる
  • 様子を見て放置する
  • 人間用の解熱剤を与える
🩹 怪我・出血

軽傷（擦り傷・小さな切り傷）

  1. 清潔な水で傷口を洗い流す
  2. 清潔なガーゼで軽く押さえて止血
  3. 犬用消毒液で消毒（人間用は刺激が強い場合あり）
  4. 包帯やガーゼで保護
  5. 帰宅後に動物病院で確認

重傷（大量出血・深い傷）

  1. 清潔なタオルで傷口を強く押さえる
  2. 5〜10分間圧迫止血
  3. 出血が止まらない場合は圧迫しながら病院へ
  4. 傷口を心臓より高い位置に保つ
  5. すぐに動物病院へ！

肉球の怪我（旅行中に多い）

  • 熱いアスファルトによる火傷
  • 砂利・岩での切り傷
  • 水洗い後に犬用靴下で保護
  • 歩けない場合は抱っこして病院へ
🤢 嘔吐・下痢

様子を見てよい場合

  • 1〜2回の嘔吐で元気がある
  • 草を食べた後の嘔吐
  • 食べすぎ・早食いによる嘔吐
  • 水分補給ができている
  • → 絶食2〜4時間後に少量の水から

すぐに病院へ行くべき場合

  • 血が混じっている
  • 繰り返し嘔吐している
  • ぐったりして元気がない
  • お腹が膨れている（胃拡張）
  • 異物を飲み込んだ可能性がある
  • 24時間以上続いている

旅行中の対策

  • いつものフードを持参する
  • 急な食事変更を避ける
  • 旅行前日は軽めの食事に
  • 車酔い対策（空腹気味で乗車）
  • 整腸剤を常備しておく
🦴 骨折・捻挫

症状の見分け方

  • 足を地面につけない・引きずる
  • 触ると痛がる・鳴く
  • 患部が腫れている
  • 変な方向に曲がっている（骨折）
  • 急に歩けなくなった

応急処置

  1. 無理に動かさない
  2. 患部を固定（添え木・タオルで）
  3. 冷やす（氷嚢・保冷剤をタオルで包む）
  4. 安静にして動物病院へ
  5. 骨折が疑われる場合は抱っこして搬送

大型犬の注意点

  • 山道・岩場での転倒に注意
  • 段差での着地衝撃
  • 他の犬との衝突
  • 車のドアへの挟まれ
  • 重い体重のため骨への負担大
🔍 迷子になった場合

すぐにやること

  1. 最後に見た場所の周辺を探す
  2. 近くの人に声をかける
  3. 最寄りの警察署に届け出る
  4. 最寄りの保健所・動物愛護センターに連絡
  5. SNS（Twitter/Instagram）で情報拡散

迷子対策グッズ

  • 迷子札（名前・電話番号を記載）
  • マイクロチップ（環境省登録）
  • GPSトラッカー（首輪に装着）
  • 蛍光色の首輪・ハーネス
  • 最新の写真を常にスマホに保存

九州の迷子犬情報

  • 迷子犬情報サイト「ペットのおうち」
  • 各県の動物愛護センターのHP
  • 地域のFacebookグループ
  • 「迷子犬 ○○（地名）」でTwitter検索
🐝 蜂・虫刺され・マムシ咬傷

蜂に刺された場合

  1. 刺された場所から離れる
  2. 針が残っていれば取り除く（ピンセット）
  3. 水で洗い流す
  4. 冷やす（保冷剤をタオルで包む）
  5. アナフィラキシーの症状（ぐったり・呼吸困難）があればすぐに病院へ

マムシに噛まれた場合

  1. 患部を心臓より低い位置に保つ
  2. 口で毒を吸い出さない
  3. 患部を締め付けない
  4. 安静にして動物病院へ（緊急）
  5. 噛まれた時刻を記録しておく

ダニが付いた場合

  1. 無理に引っ張らない（頭が残る）
  2. ダニ取りツールで根元から取る
  3. 取れない場合は動物病院へ
  4. 取った後も患部を観察
  5. 予防薬の定期投与が最善策

🚫 犬に危険な食べ物・植物

🚨 絶対に与えてはいけない食べ物

ネギ類（玉ねぎ・ニラ・ニンニク）

溶血性貧血を引き起こす。加熱しても毒性は消えない。少量でも危険。

チョコレート・カカオ

テオブロミンが中毒を引き起こす。嘔吐・下痢・痙攣・最悪死亡。

ブドウ・レーズン

急性腎不全を引き起こす。少量でも危険で、原因物質はまだ不明。

キシリトール（ガム・歯磨き粉）

低血糖・肝不全を引き起こす。人間用歯磨き粉・ガムに含まれる。

マカダミアナッツ

後肢麻痺・嘔吐・発熱を引き起こす。ハワイ土産のお菓子に注意。

アボカド

ペルシンという成分が中毒を引き起こす。果肉・種・皮すべて危険。

アルコール

人間の10分の1の量で中毒症状。嘔吐・呼吸困難・昏睡。

生の鶏・豚肉

サルモネラ菌・カンピロバクター感染のリスク。バーベキューの生肉に注意。

🌿 旅先で注意すべき危険な植物

ドングリ

タンニンが腎臓障害を引き起こす。秋の山道で落ちていることが多い。

アジサイ

青酸配糖体が含まれる。嘔吐・下痢・興奮。梅雨の公園に多い。

スイセン

全草が有毒。嘔吐・下痢・痙攣。春の花壇・公園に多い。

ツツジ・サツキ

グラヤノトキシンが含まれる。九州の山に自生。嘔吐・下痢・心臓への影響。

  • フィラリア・ノミダニ予防薬の投与

  • ワクチン証明書の準備

  • 愛犬の写真を最新のものに更新
  • 迷子札・マイクロチップの確認
  • 体温・体調の確認

📋 旅行中

  • 朝の体調チェック（食欲・排泄）
  • 水分補給を忘れずに
  • 日陰・休憩を定期的に
  • 異変を感じたら早めに病院へ
  • 無理なスケジュールを避ける

  • 消毒液（犬用）

  • ピンセット（ダニ取り）
