# Daisy Kyushu Dog Guide

Daisyと探す、九州の犬連れおでかけ。

GitHub Pagesで公開できる静的サイトです。

## 公開URL予定

https://daisy-kyushu.github.io/daisy-kyushu-dog-guide/

## 最初にやること

1. このフォルダをGitHubの `daisy-kyushu-dog-guide` リポジトリにアップロード
2. GitHub Pagesを有効化
3. 楽天アプリケーションIDと楽天アフィリエイトIDをGitHub Secretsへ登録
4. Actionsを手動実行して `products.json` を更新
5. サイトを確認

詳しい手順は `docs/github-pages-deploy.md` を見てください。
